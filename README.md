# 2023-it-help-ironman

This project contains my personal notes while learning about **Network Science** and **Graph Neural Networks** (GNN).  

## Project structure

- `docs/articles` – 30 days of learning notes and related references.
- `src` – small Python scripts used in the posts.
- `notebooks` – Jupyter notebooks used for experiments.
- `images` – figures referenced by the notes.
- `libs` – third‑party JavaScript libraries for graph visualization demos.

The notes are written in Mandarin and cover introductory concepts, links to online courses, and readings of several recent GNN papers.
